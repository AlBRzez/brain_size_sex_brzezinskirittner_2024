# Disentangling the effect of sex and brain size on brain morphometry and cognitive functioning

This repository contains the code used for creating the results presented in _Disentangling the effect of sex and brain size on brain morphometry and cognitive functioning_.

Brzezinski-Rittner, A., Moqadam, R., Iturria-Medina, Y. et al. Disentangling the effect of sex from brain size on brain organization and cognitive functioning. GeroScience 47, 247–262 (2025). [https://doi.org/10.1007/s11357-024-01486-5](https://doi.org/10.1007/s11357-024-01486-5)
